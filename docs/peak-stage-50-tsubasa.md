# 巅峰之路 · 第 50 关：足球小将全明星

> 固定特别 Boss，不参与全局种子抽签。当前首发平均 CA **780**（与 41–50 段曲线一致），球员潜力上限按角色分为 **PA 1300–1500**。
> 球员为《足球小将》架空角色，不对应真实赛季；姓名和俱乐部名仅用于原型玩法测试。

## 设计定位

- **关卡不变**：仍是第 50 关，目标 CA 780；玩家在第 50 关面对的当前强度与普通生成队同一档。
- **上限不同**：16 名球员的 `PA` / `ceilings` 按角色拉到 **1300–1500**，表达“球星级别”的差异化潜力；当前 `attrs` 仍由 780 校准，比赛不会因此变强。
- **固定名单**：和 81–100 关世界杯国家队一样是静态数据，所有玩家看到同一支球队。
- **视觉/战术**：蓝色球衣 + 黄色饰边，4-3-3，边路进攻、短传、快速、高位防线、高压逼抢。

## 数值说明

- **当前 CA** 是冻结快照里 `attrs` 的实际首发/球员 CA；全队首发平均精确为 **780**。
- **潜力上限 1300–1500** 是每名球员按角色分配的 `ceilings` / `pa`；它不参与当前比赛结算，只表示球星级别上限。
- 因此第 50 关的难度仍由 780 当前能力决定；上限差异不会让这一关变成 1500 CA 的 Boss。大空翼仍是唯一的 1500 上限，其他角色按球星层级分布。
- 快照由 `npm run pve:freeze` 生成并校验，内容 hash 会随名单/属性更新。
## 获胜奖励：选 1 人入队

首次击败第 50 关后，可从上面 16 人中**选择 1 人**加入自己的阵容：

- **按当前 CA 入队**：不重新压到 780，也不统一拉到 1500；选谁就保留谁的当前 CA。
- **保留逐人 PA**：例如大空翼 1500、日向 1480、若林 1470；其他角色按 1300–1500 的球星层级分布。
- **每账号限领一次**：领取记录写入 `pve.peak.reward50`，重打第 50 关不会重复发人。
- **阵容上限 30 人**：满员时必须先裁掉一名球员，奖励不会自动替换阵容。
- **唯一实例 ID**：入队时生成新的 `Player.id`，模板身份只保留在 `seedId`/模板 id 中；同一账号不会出现两个相同实例。
- **不同玩家可以拥有同一个角色**：每个账号各持有一个独立实例，互不影响；不是“全服唯一大空翼”。

联机账号如果后续接入服务器发奖，应把“已通关第 50 关 + 未领取 + 选择在 16 人名单内”放到服务器校验，避免只靠本地存档。
