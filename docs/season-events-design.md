# S3 起的赛季活动页 · 讨论稿 v0.6

**已明确的方向**：从 S3 起，每个赛季都有活动页；不同赛季换玩法与奖励，可用金钱、彩书、高潜力新人等。目前聚焦两条互补路线：**3D 球门前手动微操闯关**（S3 点球大战、候选 C 任意球实验室）与 **2D 公平构筑竞技**（候选 B 八人轮抽瑞士轮）。**S3 当前方向**：每日限次的手动点球挑战，目标约三个参与日通关。关数、次数、卡包规格、具体参数和奖励均为讨论值，后续赛季未排期。下文是供修改的一版方案，不代表已上线或已排期。

## 1. 活动页承担什么

玩家打开页面，先看到「本季玩什么」「最终能拿什么」「下一步做什么」。例如 S3 进行到第二关时，首页显示：**十二码之夜｜已过 1/9 关｜今日剩余 3/4 次｜通关可选主题彩书｜挑战第二关**。次数用完后显示下次刷新时间。奖励内容和领取条件在开玩前可见。

建议整季开放，不要求每日签到。活动与正式杯赛分开：玩家自行决定何时玩，不改联赛排期，也不把活动中的体能消耗、伤病或临时轮抽球员带回联赛。首版先不设活动币、活动商店或全服排行榜；每季可在 3D 微操闯关与 2D 构筑赛制之间轮换。过季的 3D 玩法可保留无奖励练习入口沉淀在挑战页。

## 2. S3：十二码之夜（点球大战）

### 节奏：九关，每天四次正式挑战（建议值）

一次指**开一关**，不是踢一球。每次最多推进一关，失败留在本关；首脚开踢时扣次，同一挑战断线续踢不再扣次。按北京时间每日零点刷新，次数不囤积，关卡进度跨日保留。即使全胜，两天最多过八关；三个参与日共十二次，有三次失手机会。三天是调难度的目标，不是截止日期。另设不扣次数的训练球，只练选脚法、瞄准和控制力度，不推进关卡或发奖。

### 一脚点球怎么踢

1. **选触球脚面和踢法**。脚面回答「用哪里碰球」：脚内侧、正脚背、外脚背；踢法回答「想踢出什么球」。脚内侧推射落点稳但球速慢；正脚背大力射门球速最快但容错小；抽射走低平、出脚快的路线，可选外脚背打出侧弯；勺子点球轻挑中路，克制提前侧扑，怕门将留中。界面推荐合理组合，不做每种脚面乘每种踢法的全排列；下一球可沿用上次选择。
2. **移动瞄准框**。在门框范围内自由拖动（键盘可用方向键），确认后锁定预期落点，再选择射门力度。框不能移出门框，但实际球可以踢偏；瞄准越贴柱，留给偏差的空间越小。
3. **用力量竖条起脚**。光标从底部起步，上下往返，点按锁定当前高度：越高，实际用力越大，不是越高越好。绿区是这名球员以当前踢法既能用上力、又能控制落点的力度范围，不固定在正中。勺子的绿区偏低，大力射门的绿区偏高；力量好的球员可以在更高力度下控住大力射门。射术影响绿区和上下两侧黄区的宽度，镇定影响光标速度。各区位置与宽度在起脚前显示，光标移动时不变；速度和宽度设上下限。
4. **按力度结算球路，再判扑救**。停在绿区，球以该踢法合适的速度飞向瞄准框，不保证进球。下黄区稍欠力，再低则明显绵软，门将有更多时间扑救；上黄区球更快但容易偏高，再高则踢飞风险大增。两端不良区都应显著降低进球率，但原因不同。回显锁定力度、瞄准框和实际球路，例如「力量过大，球越过横梁」。不额外掷隐藏进球率。

### 玩家当门将：圆形方向盘，一推即扑

有对手主罚的回合由玩家守门。前面的单向射门练习仍只练射门；首次守门给一次不扣次数的教学球。首版不再加一根需要按绿区的条：射手的操作是控制力度，门将的操作是读人和决定是否提前出击。

- **方向与操作**：门将视角，按住圆盘中心观察来球。向左上推就扑画面左上，向右下推就扑右下；越过中心防误触圈即按该角度起扑，无需松手或再按确认。滑动距离不控制力度，方向锁定后不能掉头。不推就留在中路。可以助跑时提前赌，也可以看清出脚后的初始球路再推；后者判断更准，但扑远角的时间更短。
- **给线索，不给答案**：赛前情报给出罚球习惯，助跑动画则给不完全可靠的提示，如支撑脚朝向。AI 在玩家锁定前确定瞄准点和踢法，不读玩家输入改方向；出脚后才显示真实球路。
- **属性怎么生效（建议）**：扑救反应缩短从推杆到起扑的时间；爆发决定起扑后蹬地有多快，相同时间内能多扑出一点距离；手控只在碰到球后影响接稳、挡出或碰球后仍漏进。先按玩家给的角度和起扑时刻判断手套能否触球，再判触球结果，不另掷属性骰子把扑反的门将移到另一侧。回放标出手套与球的最近位置，让玩家区分「扑晚了」和「碰到了但没挡住」。

### 九关草案：前六关练一件事，最后三关拼在一起

| 关 | 场景 | 过关目标（建议） |
|---|---|---|
| 1 | 找准脚感：无门将，大目标 | 三罚内命中目标一次 |
| 2 | 贴地推射：瞄准左右下角 | 三罚内攻入一次下角球 |
| 3 | 攻守换位：首次自由选踢法，穿插对手主罚教学 | 三罚进两球，并完成一次手动守门（不要求扑出） |
| 4 | 半步之差：门将站位靠前、反应快 | 三罚内进两球，可尝试正脚背大力射门 |
| 5 | 外脚背挑战：门将偏守一边 | 三罚内用外脚背抽射得分一次 |

## 3. 后续赛季候选池（保留 B 与 C，编号方便讨论，不是排期）

### 候选 B · 星秀轮抽杯（2D · TCG 八人轮抽 + 瑞士轮）

与 S3 的 3D 手动操作形成反差，本活动全程采用现有 **2D 比赛引擎与战术体系**，主打「零门槛公平构筑 + 体验高练度神卡阵容」：

- **八人同桌轮抽（1 玩家 + 7 AI）**：效仿集换式卡牌（TCG）轮抽机制，玩家与 7 名具有不同建队偏好的 AI 教练（如传控渗透、高空双塔、防反快马、高压逼抢等）同桌选人。首包打开 **12 名球员**，玩家先从中挑走 1 人，将剩余 11 人传给下家 AI，同时接过上家 AI 传来的 11 人包继续挑选。建议采用两轮大包（奇偶包反向传包，每包 12 人抓 10 轮、淘汰末尾 2 张余卡；或按定额包轮转抓满），最终桌上 8 人各自选满 **20 名球员**组成独立参赛队。玩家既要凑齐门将与各线轮换、搭配技能协同，也能观察传过来的余卡信号判断上下家在抢什么位置。
- **全员成品高能卡（CA 800–1400）**：卡包内全部是已经培养成型的球员卡，CA 分布在 **800–1400** 之间（平时联赛中前期难以凑齐的高练度成品卡，自带成型属性侧重与技能组合，按稀有度分档控制每包上限，并在发包池内做门将与基础位置保底，防止整桌断门将）。所有轮抽球员仅限本活动内使用，不带回正式俱乐部。
- **2D 瑞士轮排位赛**：选满 20 人后，玩家自由排定阵型、职责、战术指令与比赛计划，与同桌 7 支 AI 轮抽队进行**瑞士轮（Swiss System）**较量（8 队标准 3 轮即可分出 3-0 至 0-3 四档名次，也可扩为 4–5 轮积分瑞士轮并按同分差、净胜球排定 1–8 名；同战绩优先配对且不重复交手）。比赛使用 2D 引擎，支持赛中换人、战术切换与场边喊话；建议每轮赛后重置体能或保留轻度轮换消耗（使 20 人大名单厚度真正发挥价值）。
- **排名奖励建议**：按最终瑞士轮排名分档发放奖励（例如第 1–2 名自选主题彩书或高潜新人，中游档位领丰厚奖金与商店点券，完赛即有保底奖；重抽机制可定为每季免费首轮定奖 + 每日限次重抽刷新个人最高名次补差价）。

### 候选 C · 任意球实验室（3D · 定位球攻防闯关）

沿用 S3「十二码之夜」的 **3D 半场微操 + 九关递进 + 每日限次 + 免费训练场** 框架，直接复用现有 3D 禁区、动态球网、小看台、本队球衣与纯 TS 确定性球路结算基建，把课题扩展到禁区外定位球博弈：

- **场景扩展**：在 S3 球门场景前增加 **3–5 人防守人墙**（支持原地起跳、安排卧草球员封堵贴地球）以及禁区内 1–2 组抢点队友与盯防后卫，球位覆盖弧顶正中、左右肋部偏侧与远端。
- **主罚与配合并重**：
  1. **选脚法与战术**：内脚背兜弧线（绕人墙入近角）、正脚背电梯球（越墙急速下坠）、外脚背抽射（外旋绕墙外侧）、贴地冷射（钻起跳人墙脚下）、战术挑传后点（找队友争顶攻门）。成功打出传跑头球配合同样计过关，不只奖励直接破门。
  2. **瞄准与弧度控制**：门框内准星定目标点，配合轻量横向弧线偏移决定绕墙轨迹。
  3. **无框渐变力量条**：延续 S3 力量条手感。主罚人的传球/射门、力量、视野与镇定决定绿区位置、宽度及弧线偏差；选择挑传配合时，接应队友的无球跑动、头球与强壮参与落点争顶判定。
- **玩家防守回合**：后半程关卡穿插防守任意球——开球前玩家可一键调整人墙封堵侧、是否起跳或安排卧草，对手出脚后切门将视角用同款圆形方向盘扑救另一侧。
- **九关节奏与主奖励建议**：与点球一致，1–6 关拆解弧线绕墙、贴地钻墙、远距电梯球、后点传中配合及人墙门将联防教学，7–9 关为多球位综合攻防决战；第三、六关首通发奖金，第九关首通提供**主罚方向或接应方向主题彩书二选一**。

## 4. 下一轮先讨论什么

- **3D 闯关类（S3 点球 / 候选 C 任意球）的阵容差距**：用本队球员有养成代入感，但新号更难冲后三关。是靠属性映射上下限保底、关键关允许临时借用 1 名主题球星操刀，还是统一用活动标准数值？
- **2D 轮抽类（候选 B）的赛程与重玩节奏**：8 人瑞士轮打 3 轮还是 5 轮？整季只抽一轮定终局排名，还是允许按日重开轮抽、按历史最佳名次分段补领奖励（既耐玩又不刷爆经济）？20 人名单在瑞士轮各场之间是否保留体能消耗以凸显替补深度？
- **大奖发给谁与重复补偿**：闯关类九关通关拿彩书、轮抽类前茅拿大奖的难度线如何对齐「约三个参与日拿满主奖励」？已拥有的彩书除标记提示外，三本齐备时折算多少商店点券或奖金？
- **赛季切换**：旧赛季的 3D 活动（点球、任意球）是否常驻保留在挑战页作为无奖励自由训练场？换季时已达标但未手动领取的奖励如何补发或保留补领期，需在开放活动前写清规则。
