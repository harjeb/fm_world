# PvE 平衡基线（P7）

> 状态：脚本与基线已完成。当前玩家成长上限约 **800 CA**；巅峰曲线仍按设计保留 **350→1300**，玩家成长上限后续提升到 **1500** 后再复测。本文档不修改 CA 曲线。

## 怎么跑

```bash
npm run balance:pve
# 只跑巅峰、指定玩家 CA、每格 30 场：
PVE_GROUPS=peak PVE_CAS=600,800,900 PVE_MATCHES=30 \
  PVE_STAGES=20,40,60,70,80,90,100 npm run balance:pve
```

- 玩家测试队：生成队 + 中性 4-3-3/均衡战术，避免随机战术干扰 CA 对比。
- 对手：`buildPeakTeam(stage)`、`legendTeamById(id)`、杯赛随机池。
- 每格主客场各半；报告常规时间胜/平/负，**晋级率 = 胜 + 平 × 0.5**（点球近似）。
- 引擎：`simulateAIvsAIState`（v2 快速结算）。

## 后续复测口径

玩家成长上限提升到 1500 后，重新跑：

```bash
PVE_GROUPS=peak PVE_CAS=800,1000,1200,1400 PVE_MATCHES=30 \
  PVE_STAGES=20,40,60,70,80,90,100 npm run balance:pve
```

验收目标：

- 「适龄阵容」（玩家 CA 接近关卡目标 CA − 50～100）晋级率 **55–70%**；
- 跨 20 关后掉到 **30–45%**；
- 最终关仍保留 30–45%，不要因当前上限直接改 CA。
