# 传奇挑战 · 50 个传奇技能与技能书

新模式的奖励层：**打赢传奇队拿彩色技能书，打平拿金色技能书，输了没有；不踢点球。**
拿到书的用法不是“直接装”，而是**在培养时带进书槽（最多 4 本），触发学习事件，按球员属性掷成功率**。

结论先说：

- **50 支队 × 1 个技能 = 50 本书。** 一队一书，赢了掉这本的彩，平了掉金，没有顺序也没有池子。
- **不新增技能槽。** 学会的传奇技能占用现有的主技能槽（4 个），所以“带哪 4 本书”本身就是策略。
- **技能书 = 携带进培养的物品。** 每轮培养最多带 4 本，每本**保底触发 1 次**学习事件（复用现有 `trigger.latestAction` 的保底机制，不新造调度器）。
- **书是永久解锁。** 拿到就一直有，学会不消耗，可以再拿去教下一个球员。限制来自球员的 4 个主技能槽和属性门槛，不来自书的数量。
- **成功率看属性。** 彩书默认要求对应主属性 ≥ 900 才是 100%，金书默认 ≥ 700；低于阈值按**平方**陡降（差 10% 就剩一半，`0.65T` 以下 2% 地板）。混合要求（速度 800 + 力量 800）取几何平均。
- 数值仍以**金档为基准**，彩档 = 金 × 1.4（沿用现有 `rainbow / silver` 的倍率习惯）。实现上新增 `legendMultiplier(tier) = tier === 'rainbow' ? 1.4 : 1`，**不要**直接复用 `skillTierMultiplier()`（那个把 gold 算成 1.2）。

## 1. 模式规则

| 项目 | 规则 |
|---|---|
| 对手 | **现有 50 支传奇队**（`src/game/data/legend-teams.ts`，每队 16 人），每队挂 1 个技能 = 1 本书 |
| 难度 | **就是现有的 `LegendTeamDef.tier`：`S+` / `S` / `A` / `B`**，不新造枚举；区间见 `legend.ts` 的 `LEGEND_TIER_CA` |
| 难度内 | 该难度的队伍**全部一开始就开**，没有队内顺序 |
| 解锁 | 顺序 **B → A → S → S+**：把一档全部队伍的彩书拿到，下一档才开；队数 7 / 22 / 17 / 4，条件按集合算，不写死数字 |
| 赛制 | 单场，90 分钟，**平局直接结束**，不进点球、不进加时 |
| 赛果奖励 | 胜 → 这队的**彩书**；平 → 这队的**证书**；负 → 无 |
| 发哪一本 | 一队一书，**没有顺序、没有池子、没有“先升金再发新”** —— 赢哪支队就掉那支队那一个技能的彩 |
| 重复挑战 | 允许。已经拿过彩了再赢 → 转成球迷 +800；只拿过金再赢 → 补彩 |
| 球员限制 | 用自己的一阵；伤病、停赛、体力照常结算（这就是“传奇”的难度来源） |
| 解锁奖励 | 每队**首次获胜**额外给球迷 + 资金（见第 3 节） |

**“不踢点球”的实现**：现在 `checkPeriodContinuous()` 只在 `this.knockout && 平局` 时 `startShootout()`。友谊赛之所以踢点球，是因为 `match/setup.ts` 里 `knockout: !context.isLeague`（约 173/184 行，`PesEngine` 和 `MatchEngine` 各一处）。
注意这个值**不是** `startXxx()` 的参数，而是在 `matchEngineFor()` 里推出来的。传奇挑战要在 `MatchContext` 加一个 `allowDraw?: boolean`，两处都改成 `knockout: !context.isLeague && !context.allowDraw`；平局自然走 `finishMatch()`。**不要**用 `isLeague: true` 冒充，那会把联赛积分/排名逻辑一起带进来。

## 2. 奖励：技能书

```
每支队只有 1 本书（1 个技能）

胜 → 这本书的彩书（已经有彩 → 转成球迷 +800）
平 → 这本书的证书（已经有彩就不给，免得降级；已经有金 → 无变化）
负 → 无变化
```

就这三行，没有第三层逻辑。举例（以第 1 队 巴塞罗那 2010-11 掉《直塞视野》为例）：

| 当前拥有 | 赢了 | 平了 |
|---|---|---|
| 什么都没有 | 《直塞视野》彩 | 《直塞视野》金 |
| 只有金 | 《直塞视野》彩 | 无变化（不会重复发金） |
| 已有彩 | 球迷 +800 | 无变化（不会把彩降成金） |

- 库存 `game.legendBooks: { id, tier }[]`，**同一个 `id + tier` 只留 1 本**，重复获得转成球迷（+500）。
- **书永不消耗**。学会不会把书用掉；培养结束后全部留在库存，一本不扣。同一本书可以依次教给队里的第二名、第三名球员。
- 同一本书可以重复用；区别只在“教会谁”。球员会了这个技能之后，再拿同一本书对他就是无效选项（已掌握）。
- 金的先学会、之后再拿彩书升档，和“一直赢”的终局相同，只是多打几场。升档只改该球员的 `skillTiers`，不占新槽，也不走槽位检查。

## 4. 技能书与学习事件

### 4.1 携带与触发

- 培养开始时 `books?: { id: LegendSkillId; tier: SkillTier }[]`，**最多 4 本**（`MAX_BOOKS = 4`）。
- 带书的培养里，每本书会在行动序列里插入一个**技能学习事件**，触发规则直接复用现有事件系统，不新造调度：
  - 平时：和其它事件一样参与 10% 的随机抽取（`EVENT_BASE_CHANCE = 0.1`），书的权重给 30（普通事件 5–40）。
  - **保底**：每本书带 `trigger.latestAction`，到点还没出就由 `guaranteedEvent()` 里的 `overdue` 分支强制弹出。
  - 一本书一轮培养里**最多触发 2 次**（`maxTimes: 2`，`once: false`），第一次失败后还能再抽到。
- 四个书槽对应四个保底点：`12 / 14 / 16 / 18`。18 次行动、每次只弹一个保底事件，正好放得下，不会互相顶掉。

> 为什么必须保底：18 次行动的随机事件期望只有 ~1.8 个，4 本书全靠抽是拿不满的。所以保底不是“优化”，是这个系统的成立条件。

### 4.2 学习事件长什么样

```
标题：技能书 ·《插花脚》
正文：书上的分解动作被画成一格一格的，教练让你先在无对抗状态下过一遍。
选项 1  照着练（显示当前成功率与要求属性）
        成功 → 学会（占用 1 个主技能槽），书保留
        失败 → 疲劳 +6，书保留
选项 2  先收起来
        书保留，本轮不再触发（把保底点让给别的书）
```

- 判定发生在**选项 1 被点下去的那一刻**，用当前（训练中已成长过的）属性，所以“先把属性练上去再学”是有效策略。
- 概率在按钮上直接显示（“成功率 31% · 要求 射门 900 / 你现在 760”），不藏。
- 技能槽满时按钮禁用，提示“主技能槽已满（4/4）”，**不允许**静默替换。

### 4.3 成功率公式

面板值直接比较，不做刻度换算（`attrs[key]` 就是面板显示值：主属性 0–1500，隐藏属性 0–20）。

```
单项：
  q(x, T) = clamp( ((x/T - 0.65) / 0.35)^2 , 0.02, 1 )

混合（2 项）：
  p = sqrt(q1 · q2)          // 两项都达标才 100%
混合（3 项）：
  p = (q1 · q2 · q3)^(1/3)
```

- **达标线 T 时 = 100%**；低于 T 之后是**平方下落**，不是线性——属性差 10% 就掉一半多。
- 降到 `0.65T` 以下统一 2% 地板（不给保底，也不给 0）。
- 下面是彩书、T = 900 时的整条曲线（UI 直接四舍五入到 1%）：

| 球员属性 | 占达标线 | 成功率 |
|---|---|---|
| 900+ | 100% | **100%** |
| 855 | 95% | 73% |
| 810 | 90% | 51% |
| 765 | 85% | 33% |
| 720 | 80% | 18% |
| 675 | 75% | 8% |
| 630 及以下 | ≤70% | 2%（地板） |

- 隐藏属性同理（以 T = 13 为例）：13 → 100%，12.4 → 75%，11.7 → 51%，11.1 → 33%，10.4 → 18%。
- 体感含义：属性只有门槛的 85% 时，成功率只剩 1/3。所以正常打法是“先把对应属性练到接近门槛，再带书进去”，而不是拿新书硬喷。
- 门槛范围（逐条见第 5 节）：金书主属性 700–900 / 隐藏属性 9–13；彩书主属性 900–1100 / 隐藏属性 12–15。**彩书的下限就是 900**，所以“900 拿满、低于 900 陡降”是全局基调。
- 金书门槛低（同技能通常是彩的 78% 左右），所以在相同属性下金书概率明显更高——这是平局奖励的补偿。
- 例：彩书要求射门 900，球员射门 760 → `(760/900 - 0.65)/0.35 = 0.556` → `0.556² = 0.31` → **31%**。
- 混合例：彩书要求 速度 900 + 力量 800，球员 850 / 700 → `q1 = 0.708, q2 = 0.413` → `sqrt(0.292) = 54%`。

> 不要复用 `branchProbability()`：它把概率夹在 `0.12–0.9`，做不出“达标 100%”。新写 `bookLearnChance()`，只读 `attrs`，不掷骰（掷骰留在 `applyEventEffect` 里，方便预览）。

### 4.4 阈值为什么定在这些数上

生成球员时属性先算 0–100 评分再换成面板值（`players.ts` 的 `makeAttributes`）：`rating = 31 + 星级×4.4 + 画像权重×27 + 噪声`，上限再加 `ceilingRoom()`（7 + 6×权重 + 1.6×星级 + 0~4）。换算成面板值后：

| 维度 | 起点 | 能达到的上限 |
|---|---|---|
| 主属性·普通（权重 0.3） | ~915 | ~1230 |
| 主属性·招牌（权重 1.0） | ~1200 | ~1580（封顶 1500） |
| 隐藏属性·普通 | ~12 | ~16 |
| 隐藏属性·招牌 | ~16 | ~20 |

由此得两条硬规则：

1. **主属性阈值只能在 600–1150 之间取。** 900 是“普通维度的起点”，意味着彩书基本要“练一点”才能拿满；1100 是“接近招牌”；超过 1250 的阈值实际只有满级球员能碰。
2. **隐藏属性阈值只能在 8–15 之间取。** 普通球员起点约 12、练满约 15–16，只有“招牌维度”的球员才从一开始就接近 16。写成 16 以上，等于把这本彩书锁给少数人，不适合当 50 个技能的通用门槛。

### 4.5 属性刻度与位置限制

同一个属性键在外场和门将身上刻度不同（`MAIN_FIELD_ATTRS` / `MAIN_GK_ATTRS`），所以书必须标适用位置，否则会出现“门将的抢断是 0–20、外场的抢断是 0–1500”这种错位。

| 要求属性 | 适用 | 面板刻度 |
|---|---|---|
| 传球 `passing` | 通用 | 0–1500 |
| 射门 / 盘带 / 抢断 / 力量 / 速度 / 加速 | 仅外场 | 0–1500 |
| 镇定 `composure` | 仅外场 | 0–20 |
| 技术 / 头球 / 视野 / 决策 / 无球 / 站位 / 预判 / 团队 / 敏捷 / 耐力 | 通用 | 0–20 |
| 反应 / 手控球 / 出击 / 一对一 | 仅门将 | 0–1500 |

- `fieldOnly` 的书不能放进门将的书槽，`gkOnly` 反之；UI 直接过滤，事件层再兜一次断言。

## 8. 平衡红线

1. **射门端收益必须用百分点，不要堆评分。** `goalGiven += (finishScore - gkScore) * 0.003`，堆 10 点评分只有 +3pp；直接给 +0.03 更可控。
2. **减耗封顶 35%，回气每场封顶 +25 点体力。** 否则 90 分钟比赛会变成“没有体力系统”。
3. **一个技能只改一个量。** 例外是射门类可以同时给 `onTarget` 和 `goalGiven`（现有 `box_hunter` 的写法）：普通运动战两项之和 ≤ +0.07，头球/任意球这种稀有场景 ≤ +0.10（它们的 base 本来就低）。
4. **不要做“必进球”。** `pGoal` 的天然上限是 `(1 - block) × onTarget × goalGiven`，`halfway_lob` 的 +0.25 已经很大，必须靠 `gkOut` 这种罕见条件兜住。
5. **球迷加成上限 +5%/场。** `fansAfterResult` 里赢一场是 `+60 + 球迷×3% + 进球×30`；如果花活技能每球加 1%，一场帽子戏法就是 +3%，已经接近“多赢一场”的量级。
6. **学习概率不要做保底成功，也不要给线性回落。** 达标 100% 已经是上限，低于门槛用**平方**下落（差 10% 就掉到一半）；`0.65T` 以下统一 2% 地板（而不是 0），是为了保留“赌一下”的选择，但不要高于 3%。
7. **上限 +200 只对没顶格的球员有意义。** 1500 是比赛评分的硬顶（`effectiveAttr` 夹 100），UI 必须写清“最多到 1500”。
8. **书的强度要能被槽位成本抵消。** 4 个主技能槽是稀缺资源：如果某个传奇技能强到“无脑必带”，说明它超模了，而不是说明其他技能弱。
9. **书是永久解锁，别用“消耗”做平衡旋钮。** 一本彩书理论上能教满整个阵容，所以稀缺性必须靠“拿到彩书难”（胜场 + 属性门槛），而不是“用一次就没了”。真正的天然上限是：每个球员 4 个主槽 + 每轮培养只有 4 个书槽、每本最多 2 次触发。
