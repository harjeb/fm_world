# 战术后续复验：预先冻结的探索方案

本文件在读取该批结果前制定。代码和指令固定；不在本批种子上调整参数后重跑并宣称独立通过。
本次是**小样本机制探索**，不是主文档 200 种子块、多重校正的正式验收。

读过首批结果后新增一项**非盲、事后诊断**：`tactics-cross-diagnostic.ts` 使用种子 30001 起、双方熟练度 1，
分别采 4-4-2 / 4-3-3、链式 normal / narrow，记录传中候选、候选胜出、动作被取消及最终出脚。
随后按该诊断观察设计实验性 `crossTiming=early`：范围 0.27L→0.35L、候选分最多 +0.12（受熟练度影响），
不改变物理 / 结算成功率。**新种子 40001–40008，8 个块**，在 4-4-2 / 4-3-3 × 对手 normal / narrow ×
双翼 fam 1 / 0.4 下比较 `early` 与 `balanced`，每格同种子主客各一场；共 **256 场**。记录传中出脚、
候选与 xG，区间未做多重校正。此项是在看到旧批结果后提出，不能冒充整体方案的事前预注册正式验收。

## 实验条件

- 两组各自严格镜像的阵容：4-4-2（已有夹具）与 4-3-3（同 18 人球员池，统一属性后调用 `autoFillLineup`，
  双方复制同一首发、槽位和角色）。不同阵型可能重新选球员 / 角色，故**不能把跨阵型差值解释为纯阵型效应**。
  原始结果保存阵容 ID、角色与位置熟练度；两队在同一阵型内逐项一致。
- 主属性存档 1005、隐藏属性 13、体力 100，同技能，不适用门将属性为 0；11 人制、`D=900`、越位开启。
  固定 `DEFAULT_PARAMS` 的 `spaceLeadScale=1, defenseCompactness=0.25, defenseMarkBuffer=3`。
- 新种子 **20001–20008**；6 种配置 × 2 阵型 × 2 熟练度（1、0.4）× 8 种子 × 主客两场，共 **384 场**。
  每个单项比较使用试验主客、对照主客共 4 场组成同一种子块；同一单元保证除被测字段外其余条件相同。
- 快反 vs 高压：只改快反 `receiving=space/mixed`，快反防守宽度均为 normal；高压熟练度 1，
  快反熟练度 1 或 0.4。不能把它当作完整高压 vs B0 的克制交互实验。
- 控制 vs 链式、双翼 vs 链式：各自只改链式 `defense.width=narrow/normal`，控制 / 双翼与其他指令不变；
  进攻方熟练度 1，链式熟练度 1 或 0.4。

## 关注指标（均先按场 / 主客 / 种子处理）

1. **宽度**：对手控球期间链式外场实际 `P90−P10`，逐秒采样、每场求均值，报告采样数和缺失。
2. **边路代价**：进攻方在开放状态下实际接到的普通传球次数，接球时 `abs(y)>HW/3` 算边路接球；其中进攻方向
   `u≥2/3` 算前场边路接球。失败传中在引擎中有时 `cross=false`，因此另用仅供埋点的对象标记识别传中来源，
   避免混入普通接球。`crossCandidates` 为开放状态决策时存在合格传中候选的次数；`crosses` 是实际常规
   传中出脚（不含任意球 / 角球），成功是出脚时预裁决，不冒充实际队友接到。开放状态在**接球时**采样，
   不等价于“出脚时已开放”；埋点不随中途恢复保存，实验每场连续跑完。报告每场计数、机会数与差值。
   无足量样本时记不确定。
3. **前插与身后球漏斗**：仅 `space` 开启且开放比赛的本方持球决策统计候选。无球端只采开放比赛期间、
   `line≥0.6` 的球员决策，按已有跑动、人数上限、球位置、身后空间门槛、原有随机试探的先后顺序各记一次；
   多人多帧是暴露而非独立比赛样本。报告 runnerBlocked、试探 / 发起、候选拒绝原因、实际计划传球、
   预结算成功 / 实际目标接球，分母和分子不可混用。
4. **结果与风险**：双方 xG、净 xG、射门、进球、越位及总传球分别报告；这里不直接更改成功率或保证克制。
5. 任务冲突按上抢 / 协防队员**本方 slot** 是否被分配盯人统计，报告任务分配帧数；埋点不抽随机数。

## 判读

每个场景、阵型和熟练度分别给差值、完整种子块与固定种子 bootstrap **未校正 95% 区间**。总计场次不是
独立样本数。多场景、多个指标、8 块会产生大量偶然信号；不据此宣布某个风格克制、否定某机制或通过平衡验收。
正式结论需冻结后的足够独立种子、机会集与多重校正，以及多阵容画像、正式规则和回放验证。
