# 球员表现统计口径

表现页和对比页只汇总已保存在 `matchHistory` / `challengeHistory` 中、实际出场超过 0 分钟的战报；不是全服所有比赛或完整职业生涯的数据库。联机双方均从同一份比赛任务战报获取记录。重复战报按比赛 ID 去重，赛事和赛季筛选在汇总前生效。

新比赛记录下列球员数据（不改变比赛随机数、判定和赛果）：

- **射正**：结算判定为进球或被门将扑救的射门，与球队射正口径一致。点球大战不计入。
- **预期进球 xG**：每次射门的引擎进球概率之和，与球队 xG 同口径。
- **创造机会**：队友接到本队最近一次成功传球后，在规定时限内直接射门；传中和角球按实际争顶成功者归属，反弹后的第二次射门不会重复计给同一次传球。直接任意球和点球不计为传球创造的机会。物理引擎采用 8 模拟秒、旧引擎采用 3 个动作步骤的时限。
- **预期助攻 xA**：该球员创造的射门机会对应的 xG 之和；**机会转化率**为这些机会中实际进球的比例。这两个字段按本项目的机会归属规则计算，不冒充第三方数据。
- **抢断成功率**：成功抢断 / 上抢尝试。每次近身上抢（含摆脱、球权未定、干净抢断和上抢犯规）算一次尝试；战术犯规和拦截传球不算上抢。
- **扑救**：门将实际扑出射门的次数，出击没收和点球大战不计。
- **评分**：本项目自定义事件评分，不是球员能力值或第三方赛后评分。每场以 6.0 为基准，加 `0.8 × 进球 + 0.5 × 助攻 + 0.1 × 射正 + 0.07 × 抢断 + 0.05 × 拦截 + 0.08 × 扑救 + min(0.4, 0.01 × 成功传球)`，减 `0.025 × 未射正次数 + 0.15 × 黄牌 + 0.6 × 红牌`，限制在 1–10 分并保留一位小数。均分按已记录的出场场次求算术平均，不以分钟加权。

上述字段在旧战报或更新前已开始的比赛中可能不存在：缺失不是零，也无法从精简战报可靠倒推。新增指标只汇总完整记录了该项的场次，并在界面显示「已记录 / 出场场次」；比率的分子和分母只取同时有完整数据的场次。无记录或分母为零时显示 `—`。旧的基础统计仍遵循原有的完整性规则。
