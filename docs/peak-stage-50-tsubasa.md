# 巅峰之路 · 第 50 关：足球小将全明星

> 固定特别 Boss，不参与全局种子抽签。当前首发平均 CA **780**（与 41–50 段曲线一致），全部球员潜力上限 **PA 1500**。
> 球员为《足球小将》架空角色，不对应真实赛季；姓名和俱乐部名仅用于原型玩法测试。

## 设计定位

- **关卡不变**：仍是第 50 关，目标 CA 780；玩家在第 50 关面对的当前强度与普通生成队同一档。
- **上限不同**：16 名球员的 `PA` / `ceilings` 全部拉到 1500，表达“全明星”的球星潜力；当前 `attrs` 仍由 780 校准，比赛不会因此变强。
- **固定名单**：和 81–100 关世界杯国家队一样是静态数据，所有玩家看到同一支球队。
- **视觉/战术**：蓝色球衣 + 黄色饰边，4-3-3，边路进攻、短传、快速、高位防线、高压逼抢。

## 数值说明

- **当前 CA** 是冻结快照里 `attrs` 的实际首发/球员 CA；全队首发平均精确为 **780**。
- **潜力上限 1500** 是所有球员 `ceilings` / `pa` 的值；它不参与当前比赛结算，只表示球星级别上限。
- 因此第 50 关的难度仍由 780 当前能力决定；上限差异不会让这一关变成 1500 CA 的 Boss。
- 快照由 `npm run pve:freeze` 生成并校验，内容 hash 会随名单/属性更新。
