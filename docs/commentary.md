# 文字直播与射门细节

## 文风调查与取舍

参考了 [BBC Sport 的足球文字直播实例](https://www.bbc.com/sport/football/live/c54g1jnpl97yt)：按比赛时刻组织事件，用事件类型区分进球、扑救、犯规、换人等，并在关键射门中说明球员、位置和结果。这里借鉴足球经理游戏的短句节奏和现场解说的重点强调，文案全部为原创，没有复制 FM 的词条；目前没有可核实的 FM 词条清单，因此不声称逐条复刻 FM。

普通传递和控球保持简短，射门、进球、扑救等使用更醒目的用语。补充的控球句只描述动作开始时真实存在的持球人和位置，不编造机会、原因或结果。比赛动作和播报随机流相互独立，增加文案不会额外消耗比赛判定随机数。

## 与比赛同步

`MatchEngine` 每次推进时记录真实事件，并立即写入对应的文字和当时比分。同一步可以产生多条文字；文字播放器只显示已经产生的条目。赛后记录保存整条播报和进球详情，不靠重新模拟历史比赛。常规联赛显示为完整 90 分钟（现实推进约 600 秒），播报数量取决于真实事件，不强行凑数。点球大战每次推进一脚，比分独立显示，条数可增加。游戏当前没有加时赛。

联赛开始后，比赛显示为 90 分钟，现实推进固定约 600 秒，两者不是同一尺度；不可暂停、加速或跳过；可不中断比赛调整战术、换人。在线联赛由服务器持续推进，离开网页仍然进行，服务器重启后根据开始时间追赶；离线联赛在页面运行时推进，关闭后重新打开时补算已过去的时间。引擎采用变长动作步：只提交已到时的动作，不提前公开未来事件；服务器更新及网络传输可能产生少量延迟。

友谊赛仍可暂停、加速和跳过，Agent 也可用 `advance_match` 分步推进或用 `play_match` 直接算完。战报、文字直播和射门详情统一显示比赛分钟；射门日志会记录机会类型、距离、角度、压力、射正基础值/保底/最终值和四结果概率。超过赛程期限、此前没有开始的比赛会事后补算。赛后文字播放器根据实际比赛时间差安排播放，但对长短间隔做了压缩，速度可调；回放的暂停和加速不会影响比赛结果。

## 进球和球员属性

正常比赛中的每粒进球保存射门地点、距离、用脚/头球、方式、情境和球门落点区域。坐标是内部场地坐标：x 从 0 到 100，y 从 0 到 64；主队向 x 增大方向进攻，客队相反。落点左右是进攻方视角，六个区域是简化模拟，并非真实的三维弹道。点球大战的命中只计入点球比分，不计入常规进球详情。

射手的惯用脚、左右路位置、第一脚触球、灵活、弱脚技能决定实际用脚；弱脚影响终结能力，头球不受弱脚惩罚。射门、镇定等属性影响瞄准区域的概率；瞄准区域与抽射/推射方式再参与射正和门将扑救判定，xG 记录该次判定概率。播报中的脚、位置、方式和落点取自这次判定，不是事后随机描述。旧比赛没有记录这些字段，无法准确补造。
