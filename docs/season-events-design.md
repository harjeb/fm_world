# S3 起的赛季活动页 · 讨论稿 v0.5

**已明确的方向**：从 S3 起，每个赛季都有活动页；不同赛季换奖励，可用金钱、彩书、高潜力新人等。**S3 当前方向**：每日限次的手动点球挑战，目标约三个参与日通关。关数、次数、具体参数和奖励均为讨论值，后续赛季未排期。下文是供修改的一版方案，不代表已上线或已排期。

## 1. 活动页承担什么

玩家打开页面，先看到「本季玩什么」「最终能拿什么」「下一步做什么」。例如 S3 进行到第二关时，首页显示：**十二码之夜｜已过 1/9 关｜今日剩余 3/4 次｜通关可选主题彩书｜挑战第二关**。次数用完后显示下次刷新时间。奖励内容和领取条件在开玩前可见。

建议整季开放，不要求每日签到。活动与正式杯赛分开：玩家自行决定何时玩，不改联赛排期，也不把活动中的体能消耗、伤病带回联赛。首版先不设活动币、商店或排行榜；每季可以用完全不同的玩法，不强制套用三关模式。

## 2. S3：十二码之夜（点球大战）

### 节奏：九关，每天四次正式挑战（建议值）

一次指**开一关**，不是踢一球。每次最多推进一关，失败留在本关；首脚开踢时扣次，同一挑战断线续踢不再扣次。按北京时间每日零点刷新，次数不囤积，关卡进度跨日保留。即使全胜，两天最多过八关；三个参与日共十二次，有三次失手机会。三天是调难度的目标，不是截止日期。另设不扣次数的训练球，只练选脚法、瞄准和控制力度，不推进关卡或发奖。

### 一脚点球怎么踢

1. **选触球脚面和踢法**。脚面回答「用哪里碰球」：脚内侧、正脚背、外脚背；踢法回答「想踢出什么球」。脚内侧推射落点稳但球速慢；正脚背大力射门球速最快但容错小；抽射走低平、出脚快的路线，可选外脚背打出侧弯；勺子点球轻挑中路，克制提前侧扑，怕门将留中。界面推荐合理组合，不做每种脚面乘每种踢法的全排列；下一球可沿用上次选择。
2. **移动瞄准框**。在门框范围内自由拖动（键盘可用方向键），确认后锁定预期落点，再选择射门力度。框不能移出门框，但实际球可以踢偏；瞄准越贴柱，留给偏差的空间越小。
3. **用力量竖条起脚**。光标从底部起步，上下往返，点按锁定当前高度：越高，实际用力越大，不是越高越好。绿区是这名球员以当前踢法既能用上力、又能控制落点的力度范围，不固定在正中。勺子的绿区偏低，大力射门的绿区偏高；力量好的球员可以在更高力度下控住大力射门。射术影响绿区和上下两侧黄区的宽度，镇定影响光标速度。各区位置与宽度在起脚前显示，光标移动时不变；速度和宽度设上下限。
4. **按力度结算球路，再判扑救**。停在绿区，球以该踢法合适的速度飞向瞄准框，不保证进球。下黄区稍欠力，再低则明显绵软，门将有更多时间扑救；上黄区球更快但容易偏高，再高则踢飞风险大增。两端不良区都应显著降低进球率，但原因不同。回显锁定力度、瞄准框和实际球路，例如「力量过大，球越过横梁」。不额外掷隐藏进球率。

### 玩家当门将：圆形方向盘，一推即扑

有对手主罚的回合由玩家守门。前面的单向射门练习仍只练射门；首次守门给一次不扣次数的教学球。首版不再加一根需要按绿区的条：射手的操作是控制力度，门将的操作是读人和决定是否提前出击。

- **方向与操作**：门将视角，按住圆盘中心观察来球。向左上推就扑画面左上，向右下推就扑右下；越过中心防误触圈即按该角度起扑，无需松手或再按确认。滑动距离不控制力度，方向锁定后不能掉头。不推就留在中路。可以助跑时提前赌，也可以看清出脚后的初始球路再推；后者判断更准，但扑远角的时间更短。
- **给线索，不给答案**：赛前情报给出罚球习惯，助跑动画则给不完全可靠的提示，如支撑脚朝向。AI 在玩家锁定前确定瞄准点和踢法，不读玩家输入改方向；出脚后才显示真实球路。
- **属性怎么生效（建议）**：扑救反应缩短从推杆到起扑的时间；爆发决定起扑后蹬地有多快，相同时间内能多扑出一点距离；手控只在碰到球后影响接稳、挡出或碰球后仍漏进。先按玩家给的角度和起扑时刻判断手套能否触球，再判触球结果，不另掷属性骰子把扑反的门将移到另一侧。回放标出手套与球的最近位置，让玩家区分「扑晚了」和「碰到了但没挡住」。

| 关 | 场景 | 过关目标（建议） |

| 1 | 找准脚感：无门将，大目标 | 三罚内命中目标一次 |

## 4. 下一轮先讨论什么

- **每日节奏**：九关、每天四次是否合适？首次手动守门的提示是否足够，让玩家看懂提前扑与等出脚的区别？
- **阵容是否拉平**：用本队球员有养成感，但新人更难冲关。是保留队伍差距、提供活动借将，还是统一用活动阵容？
- **大奖发给谁**：当前草案是九关通关拿彩书。是否改为累计参与即可拿主奖励，把全胜只作为个人纪录？
- **赛季切换**：旧活动是否保留练习入口？已达标但未领取的奖励，是自动补发还是保留领取期？需在开放活动前向玩家写清楚。
